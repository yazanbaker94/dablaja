باختصار

لا يبدأ التقاط الصوت تلقائياً. بعد ضغط المستخدم زر البدء، يُرسل صوت التبويب الحالي مباشرةً إلى Google Gemini. لا تحفظ الإضافة الصوت أو النصوص. قد تُرسل أعطال مختصرة وملاحظاتك إلى audiofetcher.com بدون صوت أو مفتاح.

البيانات التي تتعامل معها الإضافة

  • مفتاح Gemini API: يدخله المستخدم ويُحفظ على جهازه في chrome.storage.local فقط، وليس Chrome Sync.
  • صوت التبويب الحالي: يُلتقط بعد نقرة صريحة ويُرسل إلى Google أثناء الجلسة فقط.
  • النص الأصلي والعربي: يُعرض مؤقتاً في ذاكرة اللوحة الجانبية ولا يُكتب في التخزين.
  • إعدادات وإحصائيات محلية: الموافقة ومستويات الصوت، ووقت الدبلجة، وعدد الجلسات، والأيام، واسم الموقع فقط عند الضغط على ابدأ (مثل youtube.com). لا تُحفظ عناوين الفيديو أو الروابط الكاملة أو النصوص أو الصوت، ويمكن مسح الإحصائيات من صفحة الاستخدام.

الاستخدام والنقل

تستخدم الإضافة البيانات لتقديم الدبلجة التي طلبها المستخدم. الصوت يذهب إلى Google. أعطال مختصرة وملاحظات إلغاء التثبيت قد تُرسل إلى audiofetcher.com/dablaja بدون صوت أو نصوص أو مفتاح أو رابط كامل. لا إعلانات ولا بيع بيانات.

تخضع معالجة Google لشروط Gemini API وسياسة خصوصية Google وفئة الفوترة الخاصة بمفتاح المستخدم. وفق صفحة الأسعار الرسمية بتاريخ السريان، قد تُستخدم بيانات الفئة المجانية لتحسين منتجات Google. راجع شروط Gemini API وسياسة Google والأسعار الحالية.

الاحتفاظ والحذف

لا تحتفظ الإضافة بالصوت أو النصوص. يُحذف المفتاح من الجهاز عند ضغط «حذف» أو إزالة بيانات الإضافة. لا تتحكم الإضافة في احتفاظ Google؛ يرجى الرجوع إلى سياسات Google.

الأمان والتحكم

  • HTTPS/WSS مشفر، واجهة مفتاح مخفية، وأزرار تغيير وحذف.
  • لا تطبع الإضافة المفتاح أو رابط الاتصال أو الصوت أو النصوص في السجلات.
  • البدء والإيقاف بيد المستخدم؛ الإيقاف يغلق الاتصال والمسارات ومعالجات الصوت والمؤقتات والمخازن.
  • أذونات Chrome محصورة بالغرض الواحد المعلن.

Limited Use

استخدام المعلومات المستلمة من Google APIs سيلتزم بسياسة بيانات المستخدم في Chrome Web Store، بما في ذلك متطلبات Limited Use. لن تُستخدم البيانات للإعلانات أو التنميط أو البيع.

التواصل والتغييرات

الإضافة غير موجهة خصيصاً للأطفال. عند النشر، ستكون قناة التواصل الرسمية هي عنوان دعم المطوّر الظاهر في صفحة الإضافة في Chrome Web Store. سيُحدّث تاريخ السريان عند أي تغيير جوهري، وستظهر الإفصاحات المطلوبة قبل التعامل مع أنواع جديدة من البيانات.
