الخلاصة

لا يبدأ التقاط الصوت إلا بعد ضغطك على «ابدأ الدبلجة». ينتقل صوت التبويب مباشرةً إلى Google Gemini باستخدام مفتاحك. لا نخزن الصوت أو النصوص. الإحصاءات المجمعة وتقارير الأعطال اختيارية وتحتاج موافقتك.

البيانات الأساسية للدبلجة

  • مفتاح Gemini API: محفوظ في chrome.storage.local على جهازك، وليس Chrome Sync، ويصل إلى Google فقط للمصادقة.
  • صوت التبويب: يُلتقط بعد نقرة صريحة ويُرسل مباشرةً إلى Google أثناء الجلسة.
  • النص الأصلي والعربي: يُعرضان مؤقتاً في الذاكرة ولا تكتبهما dablaja في التخزين أو الملفات.
  • الإعدادات وإحصاءاتك: مستويات الصوت والموافقة وإحصاءات الجلسات تبقى محلياً ويمكن مسحها.

المشاركة الاختيارية مع AudioFetcher

بعد موافقتك فقط، ترسل الإضافة معرف حدث عشوائياً لمرة واحدة، وفئة الموقع (YouTube أو X أو Twitch أو أخرى)، ومدة الصوت المدبلج. تُخزن المجاميع اليومية، ويُحذف معرف الحدث خلال 8 أيام. لا يُرسل رابط أو عنوان أو صوت أو نص أو مفتاح أو معرف دائم.

ضمن الموافقة نفسها، قد ترسل الإضافة عند فشل جلسة معرف حدث عشوائياً، ورمز الخطأ ورسالة تقنية مختصرة، والحالة، وفئة الموقع، وإصدار الإضافة وعدد محاولات الاتصال. الاحتفاظ حتى 45 يوماً. رفض المشاركة لا يمنع الدبلجة.

الملاحظات وإلغاء التثبيت

إذا اخترت إرسال نموذج، يصلنا السبب والرسالة والبريد الاختياري ومصدر النموذج ومعرف تثبيت عشوائي. قد تعالج خوادم الويب عنوان IP وبيانات الاتصال المعتادة للأمان والتشغيل. نحتفظ بالنماذج حتى 180 يوماً.

المستلمون والأغراض

يستلم Google مفتاح API وصوت التبويب لتقديم الدبلجة وفق شروط Gemini API وسياسة Google. تستضيف AudioFetcher وخدمات استضافتها الإحصاءات الاختيارية وتقارير الأعطال والنماذج، ولا تستلم الصوت أو النصوص أو المفتاح. لا نبيع البيانات ولا نستخدمها للإعلانات أو التنميط.

الاحتفاظ والأمان والتحكم

لا تحتفظ الإضافة بالصوت أو النصوص. يبقى المفتاح والإعدادات محلياً حتى حذفها أو إزالة الإضافة. تستخدم الاتصالات HTTPS/WSS. يمكنك حذف المفتاح والإحصاءات المحلية ورفض المشاركة الاختيارية دون فقدان الوظيفة الأساسية.

Chrome Limited Use

استخدام المعلومات المستلمة من Google APIs يلتزم بسياسة بيانات مستخدم Chrome Web Store، بما فيها متطلبات Limited Use، ويقتصر على تقديم الدبلجة والترجمة التي طلبتها.
